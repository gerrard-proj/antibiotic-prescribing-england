# Antibiotic Prescribing in England — Excel Data Analysis

**Independent portfolio project by Gerrard Hall**

## Overview
This project uses publicly available UK healthcare data to investigate how antibiotic consumption in England changed between 2019 and 2024.

The analysis was completed independently in Microsoft Excel, focusing on data cleaning, percentage-change calculations, year-on-year analysis and data visualisation.

## Research question
**How has antibiotic consumption in England changed over time from 2019 to 2024?**

## Data source
UK Health Security Agency (UKHSA), *English Surveillance Programme for Antimicrobial Utilisation and Resistance (ESPAUR) 2024 to 2025 report*.

Specifically: Chapter 3 data tables, Table 1 — Total antibiotic consumption by prescriber setting, England, 2019 to 2024.

Measure: defined daily doses per 1,000 inhabitants per day (DID).

Official source:
https://www.gov.uk/government/publications/english-surveillance-programme-for-antimicrobial-utilisation-and-resistance-espaur-2024-to-2025-report

## Methods
The dataset was organised in Excel into a clean table containing year and total antibiotic consumption (DID).

Analysis included:
- Overall percentage change from 2019 to 2024
- Highest and lowest consumption years
- Year-on-year percentage changes
- A line chart showing the trend
- A short descriptive interpretation

Overall percentage change:
`(2024 value - 2019 value) / 2019 value × 100`

## Key findings
- Consumption decreased from **17.889 DID in 2019** to **15.872 DID in 2021**.
- Consumption then increased each year from 2022 to 2024.
- Consumption reached **17.530 DID in 2024**.
- Overall, 2024 was approximately **2.01% below the 2019 level**.
- The lowest value in the dataset occurred in **2021**.

These findings describe the observed data and do not attempt to establish causes.

## Year-on-year changes
